⚠️ Cross-Site Scripting (XSS)

XSS allows attackers to inject malicious scripts into web pages.

💀 How to Exploit:

Register with username containing JavaScript:

<script>alert('Hacked')</script>

When you login, the script will execute!

⚠️ Impact:
  • Steal cookies/sessions
  • Redirect to malicious sites
  • Steal user credentials
✅ How to Fix:

Escape user input using escape() or | safe in templates:

{{ '{{ username | escape }}' }} {# Escapes HTML #}
{% else %}
🟢 XSS is Blocked!

The secure version escapes all user input:

{{ '{{ username | escape }}' }}

This converts <script> to &lt;script&gt;

🔍 Try It Yourself:

Try registering as <script>alert('XSS')</script>

It will show as plain text, not execute!
