📚 What is XSS?
{% if mode == 'vulnerable' %}
⚠️ Cross-Site Scripting (XSS)

XSS lets an attacker get their own script to run inside someone else's browser session.

💀 How to Exploit:

Register with a username of:

<script>hackedBanner('XSS')</script>

When your dashboard greets "Welcome, <username>!", the script runs.

⚠️ Impact:
  • Steal cookies / session tokens
  • Redirect to a malicious site
  • Silently perform actions as the victim
✅ How to Fix:

Let Jinja2 autoescape the output (its default) instead of marking it | safe:

Welcome, {{ '{{ username }}' }}!
{% else %}
🟢 XSS is Blocked!

The secure version lets Jinja2's default autoescaping do its job:

Welcome, {{ '{{ username }}' }}!

This turns <script> into &lt;script&gt; on render, so it displays as text.

🔍 Try It Yourself:

Register as <script>hackedBanner('XSS')</script> — it'll show up as plain text on your dashboard.
