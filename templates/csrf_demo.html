📚 What is CSRF?
{% if mode == 'vulnerable' %}
🔴 Cross-Site Request Forgery

The real /transfer endpoint doesn't check where the request came from or whether the person meant to send it — only that a valid session cookie is attached, which your browser does automatically on every request to the site.

💀 How to Exploit:

Trick a logged-in user into visiting a page with a hidden auto-submitting form pointed at /transfer. Their browser sends the request with their cookies attached — the server can't tell it apart from a request the user actually meant to make.

⚠️ Impact:
  • Money moved without consent
  • Settings changed silently
  • Any state-changing action the victim's account can perform
✅ How to Fix:

Issue a random, per-session token and require it on every state-changing form. An outside site can embed a form, but it can never know your token, so its submission fails.
