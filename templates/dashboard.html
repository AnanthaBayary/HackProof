{% if mode == 'vulnerable' %}
🔴 Business Logic Vulnerability

The transfer function doesn't validate the amount at all:

sender.balance -= amount # no validation!
💀 How to Exploit:

Transfer a negative amount (e.g. -500) to any user — subtracting a negative number increases your own balance instead.

✅ How to Fix:
  • Reject amounts ≤ 0 or above a sane max
  • Check the sender actually has enough balance
  • Require a CSRF token so this can't be triggered from another site
{% else %}
🟢 Validation Added

The secure version validates the amount and the request itself:

if amount <= 0 or amount > 10000:
    reject()
if sender.balance >= amount:
    sender.balance -= amount
🔍 Try It Yourself:

Try transferring -500 — it's rejected before it ever touches the database.
